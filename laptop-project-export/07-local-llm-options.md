# Local LLM Options

## Goal

Identify free/open-source local LLM tools similar to Ollama that can run on a laptop or homelab server.

## Options Discussed

### Ollama

Simple local LLM runtime. Good for pulling and running models quickly.

### LM Studio

Desktop-friendly local LLM app with GUI. Good for testing models locally.

### Jan

Open-source ChatGPT-like desktop app for local AI.

### LocalAI

Self-hosted OpenAI-compatible API server for local models.

### llama.cpp

Low-level and efficient runtime for running GGUF models locally.

### GPT4All

Desktop app for running local models with a simple UI.

## Recommendation

For homelab/server use:

```text
Ollama + Open WebUI
```

For desktop experimentation:

```text
LM Studio or Jan
```

For API compatibility:

```text
LocalAI
```
