# Ubuntu Server Important Commands

## Update System
```bash
sudo apt update
sudo apt upgrade -y
```

## Check IP
```bash
hostname -I
```

## Check Disk Space
```bash
df -h
```

## Check RAM
```bash
free -h
```

## Check CPU
```bash
lscpu
```

## Reboot
```bash
sudo reboot
```

## Shutdown
```bash
sudo shutdown now
```
